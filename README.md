# Orbit

Windows-застосунок для швидкого запуску дій через радіальне меню. Дизайн на основі Geist: монохромний інтерфейс, невеликі заокруглення, темна та світла теми.

Orbit — один виконуваний файл на Rust (інтерфейс — [egui](https://github.com/emilk/egui)), без Electron, Node.js чи .NET.

## Запуск

Завантаження: [GitHub Releases](https://github.com/Validolio11/Orbit/releases/latest).

- `Orbit-Setup-<версія>.exe` встановлює Orbit для поточного користувача в `%LOCALAPPDATA%\Programs\Orbit` без прав адміністратора, з ярликами на робочому столі й у меню «Пуск». Попередня версія Orbit (зокрема на Electron) закривається й замінюється; меню й налаштування в `%APPDATA%\Orbit` лишаються. Видалити можна в «Параметри → Програми». Тихе встановлення: `--silent --nolaunch`.
- `Orbit-<версія>-windows-x64.exe` — портативна копія: просто запустіть.

Розробка (Windows x64, [Rust](https://rustup.rs) stable):

```powershell
cargo run            # редактор і колесо
cargo test           # перевірка налаштувань, переміщення дій, геометрії, аргументів, каталогу програм
cargo build --release
```

Під Linux/macOS Orbit теж збирається й запускається для роботи над інтерфейсом, але без перехоплення миші, трею й команд Windows. `ORBIT_DATA_DIR` задає окрему папку налаштувань, `ORBIT_FAKE_APPS` — JSON зі списком програм для діалогу вибору.

## Як користуватися

- Бічна кнопка Mouse 4 відкриває колесо біля курсора. У «Керування» можна вибрати Mouse 5.
- Альтернативний виклик: **Ctrl + Space**.
- За замовчуванням затримайте курсор над дією для запуску. У «Керування» також є запуск відпусканням бічної кнопки або клацанням.
- Наведення на групу відкриває її вкладене колесо. Центральна кнопка повертає на попередній рівень. Щоб групи відкривались лише після кліку, у налаштуваннях «Вибір дії» оберіть «Відкривати вкладки» → «Клацання мишею».
- **Esc** скасовує вибір, зупиняє відкладений запуск і закриває колесо.
- У «Налаштування → Зовнішній вигляд → Розмір кола» можна змінити масштаб від 60% до 150%, повернути 100% і одразу перевірити меню. Зміни зберігаються автоматично та застосовуються під час наступного виклику. На невеликих екранах колесо вміщується в робочу область.
- У «Налаштування → Поведінка колеса» є перемикач «Закривати меню натисканням поза ним». За замовчуванням увімкнений; підтримує натискання поза фактичним колом, у тому числі в інших вікнах. При закритті скасовується відкладений вибір.
- У клавіатурному режимі: стрілки — вибір сектора, **Enter** — виконання або відкриття групи, **Backspace** — назад.
- У редакторі натискання на звичайну дію або її олівець відкриває редагування.
- У попередньому перегляді натискання на іконку чи сектор групи відкриває її вміст. Рядок групи теж відкриває вкладене меню; олівець поруч редагує групу. Центр колеса або «Назад» повертає вище.
- Щоб перемістити дію у вкладене меню, перетягніть її рядок на групу в списку «Дії в меню». Група підсвічується перед відпусканням; зміни зберігаються автоматично. Звичайні папки на диску залишаються діями запуску, вкладені меню мають тип «Група».
- У попередньому перегляді можна перетягувати іконки й сектори, щоб змінювати порядок. Якщо перетягнути пункт у центр вкладеного кола, він переміститься на один рівень вище.
- Щоб повернути пункт із групи одразу на головне коло, натисніть значок стрілки з квадрата в його рядку. Підказка: «Перемістити в головне меню».
- Для додавання програми відкрийте «Застосунок» і клацніть її плитку; пошук звужує список, а галочками можна додати кілька програм разом. Шлях та аргументи доступні у «Додатково»; поруч є вибір файлу та введення URL.
- Кошик у рядку дії або групи видаляє її з меню після підтвердження.
- Кнопка закриття згортає Orbit у трей. Остаточний вихід — «Вийти з Orbit» у меню іконки біля годинника.

До кожного колеса можна додати до 12 дій; доступні до 20 окремих меню.

## Типи дій

| Тип | Дія |
|---|---|
| Застосунок | Запуск `.exe`, `.lnk` або відкриття http(s)-посилання |
| Папка | Відкриття локальної директорії у Провіднику |
| Скрипт | Запуск `.ps1`, `.py`, `.js`, `.cjs` з аргументами (`.js` потребує Node.js) |
| Windows | Провідник, диспетчер завдань, параметри, знімок екрана, звук, медіа, робочий стіл, блокування |
| Група | Вкладене радіальне меню |

Група Adobe з Illustrator, After Effects і Photoshop з’являється в початковому меню, лише якщо Orbit знайде ці програми у стандартних директоріях Adobe. Для Python-скриптів потрібен `py.exe`; PowerShell використовує поточні правила виконання Windows.

## Дані

Налаштування зберігаються локально в `%APPDATA%/Orbit/settings.json` у тому самому форматі, що й у версії на Electron. Перед кожним збереженням попередня версія копіюється в `settings.json.bak`; пошкоджений файл відкладається, і Orbit відновлюється з копії. Є імпорт та експорт JSON. Імпорт перевіряє структуру, типи команд і місткість меню. Програма не потребує облікового запису.

## Оновлення

У «Налаштування → Оновлення» натисніть «Перевірити оновлення», потім «Завантажити». Коли нова версія готова, натисніть «Установити й перезапустити».

Orbit бере стабільні версії з [Validolio11/Orbit](https://github.com/Validolio11/Orbit) і перевіряє SHA-256 файлу. Поточний `Orbit.exe` відходить убік як `Orbit.exe.old` (видаляється під час наступного запуску), новий стає на його місце; якщо щось пішло не так, повертається попередній. Меню й налаштування не змінюються.

Версії на Electron (0.1.x) не вміють завантажувати нову збірку: один раз встановіть `Orbit-Setup-<версія>.exe` вручну.

### Публікація нової версії

Підніміть `version` у `Cargo.toml`, закомітьте й надішліть тег:

```powershell
git tag v0.2.0
git push origin main --follow-tags
```

Або без терміналу: GitHub → Actions → «Release Orbit» → «Run workflow» на гілці `main` — тег `v<версія з Cargo.toml>` створиться сам.

GitHub Actions на Windows запускає тести, збирає `Orbit.exe`, перевіряє його запуск і встановлення та публікує GitHub Release з контрольними сумами. Версія тегу має збігатися з `Cargo.toml`. Кожен push також збирає `Orbit.exe` як артефакт робочого процесу «Build Orbit».

## Структура

- `src/main.rs` — запуск: встановлення, один екземпляр, права адміністратора, завантаження налаштувань.
- `src/model.rs` — налаштування, перевірка, переміщення дій, аргументи, геометрія колеса (з тестами).
- `src/storage.rs` — надійне збереження з резервною копією.
- `src/platform/win.rs` — хук миші (Mouse 4/5), Ctrl + Space, трей, запуск програм, іконки Shell, автозапуск, завдання «Orbit (administrator)».
- `src/catalog.rs` + `assets/discover-apps.ps1` — каталог встановлених програм.
- `src/launcher.rs` — запуск дій, папки й скрипти для вибору.
- `src/updater.rs`, `src/install.rs` — оновлення й встановлення.
- `src/ui/` — редактор, діалоги, колесо (`wheel.rs`, `overlay.rs`), тема Geist.
- `docs/design.md` — джерела й рішення дизайну.

Шрифт Geist (SIL Open Font License, `assets/fonts/OFL.txt`) вбудований у виконуваний файл.
